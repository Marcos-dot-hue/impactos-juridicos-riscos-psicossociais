# Projeto Nexus Legal: Impactos Jurídicos na Gestão de Fatores de Riscos Psicossociais

Repositório oficial de pesquisa e documentação focado na análise do enquadramento legal, conformidade trabalhista (Compliance) e na gestão estratégica dos fatores de riscos psicossociais no ambiente corporativo.

---

## 🎯 **Sobre o Projeto**
Este projeto investiga a intersecção entre a segurança jurídica e a saúde mental organizacional, avaliando as implicações legais, normativas e a responsabilidade civil/trabalhista das empresas diante dos fatores de riscos psicossociais no trabalho.
